## 1. 项目概述

### 1.1 背景

本项目为纯本地桌面版 HTML 交互系统的功能扩展，基于 Electron 框架构建，采用 IndexedDB 作为本地数据存储。需在现有系统导航中新增两大核心功能模块：

- **软件快速发布**（开发者管理 > 软件快速发布）
- **软件更新设置**（系统管理 > 软件更新设置）

### 1.2 核心目标

| 目标 | 描述 |
|------|------|
| 开发效率提升 | 一键打包源码文件夹，快速生成可分发的软件包 |
| 用户体验优化 | 自动检测更新、一键升级，数据无缝迁移 |
| 数据安全保障 | IndexedDB 数据备份、迁移、回滚机制完善 |

### 1.3 技术栈

| 层级 | 技术选型 |
|------|---------|
| 运行时 | Electron 28+ |
| 前端框架 | Vue 3 + TypeScript |
| UI 组件库 | Ant Design Vue 4.x |
| 本地存储 | IndexedDB (Dexie.js 封装) |
| 打包工具 | Node.js fs/archiver |
| 构建工具 | Vite + electron-builder |

### 2.2 软件更新设置模块

#### 2.2.1 检测路径配置

| 路径类型 | 描述 | 示例 |
|----------|------|------|
| 本地路径 | 本地文件夹路径 | `D:\software\update`、`~/Downloads/updates` |
| 网盘同步路径 | 主流网盘本地同步文件夹 | 百度网盘同步文件夹、阿里云盘同步目录 |

**路径管理功能**:
- 添加/编辑/删除检测路径
- 路径有效性验证
- 路径类型标识（本地/网盘）

#### 2.2.2 检测策略

| 策略 | 描述 | 配置项 |
|------|------|--------|
| 手动检测 | 用户点击"检查更新"按钮触发 | - |
| 自动检测 | 后台定时检测 | 周期：启动时 / 每N小时 |

**检测流程**:
1. 扫描所有配置路径
2. 查找有效软件包（含 version.json）
3. 读取版本信息并与当前版本对比
4. 显示检测结果

#### 2.2.3 版本对比与提示

| 功能点 | 描述 |
|--------|------|
| 版本读取 | 从本地与软件包的 version.json 获取版本号 |
| 版本对比 | 按语义化版本规范对比（major.minor.patch） |
| 更新提示 | 检测到新版本弹出提示框，显示：版本号、发布时间、更新内容 |
| 提示控制 | 可配置：同一版本仅提示一次 / 每次检测都提示 |

#### 2.2.4 自动更新执行

**更新流程**:

```
[立即更新] → 备份当前版本 → 下载/拷贝软件包 → 解压/替换文件 → 数据迁移 → 重启软件
```

| 步骤 | 描述 | 容错机制 |
|------|------|---------|
| 1. 备份 | 备份当前软件文件 + IndexedDB 数据到指定路径 | - |
| 2. 拷贝 | 将软件包拷贝到临时目录 | 失败则中止 |
| 3. 解压 | 解压 ZIP 软件包（若为 ZIP 格式） | 失败则回滚 |
| 4. 替换 | 替换软件文件，保留用户配置与数据 | 失败则回滚 |
| 5. 迁移 | 执行 db-migration.js 进行数据结构迁移 | 失败则回滚 |
| 6. 完成 | 提示更新成功，提供重启按钮 | - |

#### 2.2.5 更新管理

| 功能点 | 描述 |
|--------|------|
| 更新日志 | 记录所有更新操作：时间、版本变更、结果、失败原因 |
| 备份管理 | 查看/删除旧版本备份 |
| 手动回滚 | 选择备份版本进行回滚 |
| 备份路径配置 | 自定义备份存储路径 |

#### 2.2.6 数据保护

| 保护项 | 描述 |
|--------|------|
| IndexedDB 备份 | 更新前完整导出 IndexedDB 数据 |
| 数据迁移脚本 | 新版本包含数据结构迁移逻辑 |
| 跨设备迁移 | 拷贝软件文件夹后可正常读取数据 |
| 自动回滚 | 更新失败自动恢复到备份版本 |

#### 2.2.7 离线支持

- 无网络环境下，本地路径检测正常工作
- 网盘同步路径已同步的文件可正常检测

## 4. 数据结构设计

### 4.1 version.json

```json
{
  "versionCode": "v1.0.0",
  "releaseTime": "2026-02-06T10:00:00Z",
  "updateContent": "1. 新增软件发布功能\n2. 新增软件更新功能",
  "md5": "d41d8cd98f00b204e9800998ecf8427e"
}
```

### 4.2 打包配置 (IndexedDB: packConfigs)

```typescript
interface PackConfig {
  id: string;
  templateName?: string;
  sourcePath: string;
  outputPath: string;
  packageName: string;
  packageType: 'zip' | 'folder';
  fileTypes: string[];
  createdAt: Date;
  updatedAt: Date;
}
```

### 4.3 更新配置 (IndexedDB: updateSettings)

```typescript
interface UpdateSettings {
  id: string;
  checkPaths: Array<{
    type: 'local' | 'cloud';
    path: string;
    enabled: boolean;
  }>;
  checkStrategy: 'manual' | 'auto';
  checkCycle: number; // 小时
  backupPath: string;
  notifyOnce: boolean; // 同一版本仅提示一次
}
```

### 4.4 更新日志 (IndexedDB: updateLogs)

```typescript
interface UpdateLog {
  id: string;
  timestamp: Date;
  fromVersion: string;
  toVersion: string;
  result: 'success' | 'failed' | 'rollback';
  errorMessage?: string;
}
```
