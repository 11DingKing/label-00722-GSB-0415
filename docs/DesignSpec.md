# 设计规范说明书 - Geek 风格

> **项目名称**: 纯本地桌面版 HTML 交互系统 - 软件发布与更新模块  
> **设计风格**: Geek / Terminal / Cyberpunk  
> **版本**: v1.0.0  
> **创建日期**: 2026-02-06  
> **状态**: 待确认

---

## 1. 设计理念

### 1.1 风格定位

**Geek Terminal Style** - 融合终端命令行美学与赛博朋克视觉元素，打造专业、极客、科技感十足的开发者工具界面。

### 1.2 设计关键词

| 关键词 | 表现形式 |
|--------|---------|
| **Terminal** | 等宽字体、命令行提示符、光标闪烁效果 |
| **Matrix** | 深色背景、荧光字符、数据流动感 |
| **Cyberpunk** | 霓虹色彩、渐变光效、几何边框 |
| **Minimal** | 扁平化、无多余装饰、信息密度高 |
| **Professional** | 清晰层次、高效布局、专业配色 |

### 1.3 情感传达

- 🖥️ **专业感** - 开发者工具的可信赖感
- ⚡ **高效感** - 快速、流畅的操作体验
- 🔮 **科技感** - 前沿技术的视觉表达
- 🎯 **极客感** - 程序员文化的认同感

**按钮交互状态**:

| 状态 | 效果 |
|------|------|
| Default | 正常显示 |
| Hover | 发光增强 + 边框亮度提升 + 轻微上移 |
| Active | 亮度降低 10% |
| Disabled | 透明度 50% + 禁用光标 |
| Loading | 显示终端风格加载动画 `[=====>    ]` |

**按钮文字风格**:
- 主按钮带终端提示符 `> ` 前缀
- 文字后带光标闪烁效果 `_`

## 7. 图标系统

### 7.1 图标风格

- **线性图标** (Outlined) 为主
- 线宽: 1.5px
- 颜色跟随文字或使用主色调
- 推荐图标库: **Lucide Icons** / **Phosphor Icons**

### 7.2 核心图标

| 功能 | 图标 | 描述 |
|------|------|------|
| 文件夹 | 📁 `folder` | 路径选择 |
| 打包 | 📦 `package` | 软件打包 |
| 下载 | ⬇️ `download` | 下载/更新 |
| 上传 | ⬆️ `upload` | 发布 |
| 设置 | ⚙️ `settings` | 配置 |
| 刷新 | 🔄 `refresh-cw` | 检查更新 |
| 成功 | ✓ `check` | 完成状态 |
| 错误 | ✕ `x` | 失败状态 |
| 警告 | ⚠ `alert-triangle` | 警告状态 |
| 回滚 | ↩️ `undo` | 版本回滚 |
| 终端 | >_ `terminal` | 命令行 |
